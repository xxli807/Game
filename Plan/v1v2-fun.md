# v1/v2 好玩度诊断 —— 四项全中意味着什么

## 一、症状（由玩家本人指出，四项全选）

1. 没有变强的爆发感
2. 怂不到，没紧张感
3. 选技能差不多
4. 没有「再来一局」的动力

**四项全中，说明这不是某个参数没调好，而是核心循环本身是平的。**

---

## 二、根因：四个症状其实是两个

幸存者类游戏的乐趣循环长这样：

```
被威胁 → 险些死掉 → 拿到升级 → 升级改变了「玩法动词」
       → 现在能碾压刚才的威胁（爆发感）→ 难度再升 → 循环
```

把这个循环拆开看，四个症状收敛到**两个根因**：

### 根因 A：升级给的是数值，不是新动词
「+10% 伤害」不会改变你按什么、走什么位。手感不变，就没有「我变强了」的那一刻。
→ 直接造成 **症状 1（没爆发感）** 和 **症状 3（技能差不多）**

### 根因 B：难度不构成威胁
死不掉，就不存在「险些死掉」。而**爆发感是相对的**——
没有前面的窒息，后面的碾压就不成其为爽点。
→ 直接造成 **症状 2（没紧张感）**，并抽掉了症状 1 的另一半

而 **症状 4（不想再来一局）是前三个的结果，不是独立问题**：
没有值得追求的强力 build，也没有惊险时刻可回味，自然没有下一局的理由。

**结论：修 A 和 B，四个症状会一起动。只修表面（比如加个每日挑战）没用。**

---

## 三、如果要修，该怎么修

### 针对 A：让升级改变动词
- **进化/合成**：两个技能合成第三个**全新**的（v2 已有部分，但触发太晚太少 →
  提前、增多，并在 UI 上明示「这两个能合」）
- **稀有度分级**：普通（数值）/ 精良（数值 + 一个效果）/ 传说（**改变玩法**，
  例如「击杀时爆炸」「攻击穿透并反弹」「移动即留下火痕」）
- **诅咒祭坛**：拿一个强力增益 + 一个真实代价（少一格血上限、怪物更快）——
  让 build 有性格，而不只是变大

### 针对 B：让难度真的威胁
- 精英怪要有**预警 + 明确的攻击模式**，而不是血更厚
- 刷怪要有**节奏**：平静 → 涌来 → 爆发 → 喘息，而不是均匀铺满
- 低血量反馈：心跳声、屏幕边缘变红 —— 让「快死了」被感觉到
- 关键：**允许玩家真的死**。现在如果死不掉，所有紧张感都是装的

## 四、诚实的成本评估

这不是补丁，是**战斗循环的重做**：升级系统要重写、刷怪节奏要重排、
精英/Boss 要加行为状态机，还要反复调平衡并真人试玩。
按这个仓库的节奏，是**以周计，不是以天计**。

而且做完之后，v1/v2 面对的仍然是 Vampire Survivors / Brotato / Survivor.io
这些有钱有团队的产品——投入产出比很低。

---

## 五、建议

**冻结 v1/v2，重心压到 v3。**

- v1 本来就是 tim.lu 的地盘
- v2 该给的都给了（剧情、层主、遗物、余烬营地、程序化音效、全中文），
  剩下的差距是**类型本身**，再投入也追不平
- 沉没成本不该成为继续投入的理由

**但两者都留在线上** —— 已经做完了、跑得好好的、不占维护成本，
`/Game/v1/` 和 `/Game/v2/` 继续挂着就行。

如果之后确实想回来救 v2，**先做根因 A**（升级改变动词）：
它比 B 便宜，而且单独做就能同时改善症状 1 和 3。
