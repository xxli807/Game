# 鼎革：连续世界实现

## 方向

用户最终选择：一个连续世界承载所有抉择，保留中国王朝主题；不是 v2 的大怪物首领关卡，也不在每次选项后切换独立小游戏。

## 已实现

- 默认开始后进入一张 1800 × 1200 的持续地图，包含关隘、粮仓、城镇、行宫、祭坛；下一事件保留玩家位置与已落实政令标记。
- 原有 12 位君王、事件、四柱、朝堂、五幕与结局继续由 App/rules/meta 管理。世界引擎独立放在 `src/game3/action/`，不 import 其他游戏。
- 靠近事件所在建筑交互，选择后在同图执行；完成后把结果交给原有王朝流程。
- 五种活动：有限守军战斗与占领、物资/人员护送、领取配送物资、三方交涉、礼制颁诏。事件 ID + 选项序号显式映射，新增事件按领域兜底。医药、修墙与人员护送有专门表现。
- 普攻自动挥刀，空格闪避、Q 破阵、R 箭雨；E 交互。触屏摇杆与按钮可用。离开页面自动暂停，议事时冻结世界。
- 交涉支持不足、车队损失、角色倒下产生执行失败；玩家执行结果决定军情与挑战成败、人才是否响应。新模式不在完成行动后再抽一次随机猝败；天命归零、资源危机、时局上限与立国条件仍生效。
- 所有新活动均可结束，结局有返回君王选择流程。结果提交带幂等保护，避免重复点击推进两次。

## 当前范围

这是连续世界的第一版：五类可复用活动承接事件，不是为每一个选项制作不同地图或独有系统。地图是同一片根据地的抽象表达，事件中的外地城名仍在王朝数据中记录。角色美术共用一位将领形象；居民为程序绘制。当前局不持久化，刷新后从大厅重新开始。未加入建筑碰撞、自由建造、无限开放世界或多人功能。

## 验证

- `npm run build`：三个游戏构建与共享 TypeScript 检查通过。
- `node .claude/skills/verify/smoke.mjs`：三个游戏控制台零报错；v3 检查真实移动、暂停与恢复。
- `node .claude/skills/verify/world.mjs`：在独立浏览器 harness 验证移动、交互距离、同事件不同活动、配送、交涉成败、颁诏时机、驻军战斗、护送、失败、跨事件位置保留。harness 内存打包，不向生产游戏注入测试后门。
- Playwright 1280px 与 390px：实际走到事件、选项返回同一 canvas、暂停恢复、真实触摸摇杆、无横向溢出与控制台错误；两种尺寸均通过完整颁诏 → 王朝结算 → 下一事件，保持同一 canvas。

## 数值口径

旧文字模式可通过 `?mode=chronicle` 保留给历史工具；平衡脚本默认使用该地址。2026-09-12 的 45 局实测为 **5 胜 / 40 败 / 0 崩殂（11%）**，34 局为「天命骤断」，控制台零错误。这是先前四柱改版后的旧模式数据，与六资源时代 47% 基准不具可比性。此次没有为匹配旧胜率而修改事件资源值。

新模式由玩家活动表现决定成功，不能把旧随机选卡胜率当作它的验收指标。目前已做活动成败功能回归；长期难度与整局时长还需要人工试玩建立基准。

## 2026-09-13 三维村庄（接手 Codex 未完成的 3D 改造）

目标：把「平面贴图上的地图」换成真正的三维场景——可操控的角色、实心建筑、可转动的镜头、在世界里交互；先做一座完整可玩的村庄，王朝抉择既改变你「做什么」，也改变「身边发生什么」。

- [x] **渲染**：`action/render3d.ts`（three.js，WebGL2）。第三人称跟随镜头：拖动/单指转视角，滚轮/双指缩放，Z/C 键旋转；竖屏自动俯角更陡。建筑挡住主角时变半透明。无 WebGL2 时自动退回原 2D `render.ts`，规则不变。
- [x] **模型**：`action/models3d.ts`（Codex 起的建筑/角色骨架 + 本次补的村民、摊位、井、车、旗、各类「政令遗迹」）。全部程序化几何体，无外部模型文件。
- [x] **村庄布局**：`action/layout.ts`——道路网（`ROAD_NODES/EDGES`，同时用于地面贴图、车队路线、村民行走）、实心碰撞（建筑、摊位、井、池塘、林木），贴墙只在墙角附近自动绕行，正面撞墙会停下。
- [x] **村民与后果**：`action/village.ts`。人群构成随四柱变化（经济→开张摊位数，军事→巡卒，天命→天气明暗）；执行政令时村民有反应（开战躲回家、施政排队、交涉围观、颁诏聚到祭坛、成功后欢呼）；每个结果留下永久建筑：夺关→驻军旗与巡卒，败→焦土；护送→货箱/流民帐篷，被劫→残车；施政→门前物资与灯、医帐/义学/钱箱/粥锅/补墙；交涉成→议事亭与属吏，败→请愿百姓长驻行宫前；颁诏→祭坛旁刻着诏令名的石碑。走近村民按 E 交谈，台词取自近期政令与四柱。政令回报弹窗写明「村中变化」。
- [x] **引擎接入**：`engine.ts` 输入按镜头朝向旋转（`cameraYaw`，默认 0 时 W 仍是北）；车队沿道路走；伏兵设在车队必经路段；出生点避开建筑。App/rules/events 未改动，数值未改动，故未重跑平衡（`?mode=chronicle` 不受影响）。

### 已知限制 / 交接
- 无头 Chromium 用 SwiftShader 在 CPU 上渲染，约 8 fps；smoke 因此按键 1.5 秒。**真机帧率未实测**，手机上若吃力，先降 `setPixelRatio` 上限或阴影贴图尺寸（`render3d.ts` 构造函数）。
- 人物仍是程序化方块人；若要更精细的角色需引入 glTF 模型与加载流程。
- 村庄只有一座；外地城名仍只在王朝数据里。遗迹按类别槽位摆放，同类过多时在原处叠加数量而不是无限铺开。
- Playwright 不在 `package.json` 里：`npm install` 会把它清掉，需要时 `npm i --no-save playwright && npx playwright install chromium`。
