# v3 平衡回归

**为什么非跑不可**：v3 的数值散在 107 个手写事件 + `rules.ts` 的加成/消耗/危机里，
肉眼看代码判断不出整体强弱。历史教训——`events.ts` 的手写事件换掉模板事件时，
数值尺度整体变大，随机胜率从 50% 一路飙到 77%，是靠抬高立国门槛才拉回来的。
固定随机选择策略提供整体难度参照，但脚本未固定随机种子，45 局仍有抽样误差；也不能替代真人或策略性试玩。

## 怎么跑

```bash
npm run build
(python3 -m http.server 8080 --directory dist &)
node .claude/skills/v3-balance/balance.mjs 45          # 沿用存档，解锁会累积（默认，也是基准口径）
node .claude/skills/v3-balance/balance.mjs 20 --fresh  # 每局清档，只用初始 4 位君王
pkill -f "http.server 8080"
```

45 局大约 3–5 分钟。改完数值想快速看一眼就先跑 20 局，定稿前跑满 45 局。

## 当前机制与历史基准

当前为军事 / 政治 / 经济 / 天命四柱，文字与 3D 各有入口。此脚本只测文字模式；3D 的交涉、护送等实际操作由 `verify/world.mjs` 检查。
四柱早期记录：2026-09-12 为 5 胜 / 40 败（11%）。最新四柱实测见 `AGENTS.md` 与 `Plan/game3-playability.md`，不可与下表的六资源版本直接比较。

2026-11-01 发布验收：45 局 **13 胜 / 32 败 / 0 崩殂（29%）**，107 个标题、零幕次错配、零模板残留、零控制台报错。沿用存档、不用君王专属；不因一次样本上升就认定难度改善。

2026-10-03 四柱历史：45 局 **9 胜 / 36 败 / 0 崩殂（20%）**，108 个标题、零幕次错配、零模板残留、零控制台报错。随机策略不使用君王专属。低胜率仍需结合策略性及真人试玩分析；具体失败分布见可玩性文档。

下表保留六资源时期的历史记录：

| 口径 | 结果 |
|---|---|
| **本脚本 45 局，沿用存档** | **21 胜 / 19 败 / 5 崩殂 = 47%**（2026-08-09 实测，commit 823123e） |
| 历史记录 | `Plan/game3-improvements.md` 记的是 17 胜 / 23 败 / 5 崩殂 ≈ 38%，当时用的是另一个一次性脚本 |
| 事件覆盖 | 108 个不同标题，模板残留 **0** |
| 幕次错配 | 靠前、靠后都是 **0** |
| 君王 | 12 位全部出现过（解锁链通畅） |
| 控制台 | **零报错** |

两个数字差 9 个百分点：n=45 时一个标准差就有约 7 个百分点，**统计上区分不开**，
而且当年那个脚本已经删了（`_*.mjs` 是 gitignore 的），选君王的方式未必和这里一样。
六资源历史版本应与 47% 这一行对照；当前四柱版本应使用四柱记录。还要保持相同存档口径。

六资源时期采用 35–55% 作为随机策略的调参参考。四柱版本仍需关注过早覆亡与稳妥路线是否有效；偏低时检查失败原因与策略性试玩，不能只为了命中一批 45 局的比例改参数。

⚠ **样本量**：6 局那种小样本毫无意义（38% 的真实胜率下，6 局里赢 5 局的概率也有约 3%）。
要下结论就跑满 45 局。想比较两次改动，两次都用同一个口径（都带 `--fresh` 或都不带）。

## 输出怎么读

- **结局分布**：当前结局由 `rules.ts` / `App.tsx` 定义，不能按六资源时期的七个名称判断。稀有结局未在 45 局出现并不证明不可达；用定向边界检查和策略性试玩排查。`verify/v3-rules.mjs` 检查立国条件与界面目标一致。
- **幕次错配**：第 N 次抉择放的一定是 `deck[N-1]`（阶段挑战也会推进 cursor），
  所以卡面的幕次必须和进度对得上。非 0 = `prepareDeck` 在某一幕的牌不够用，回退到了全池抽牌。
- **模板残留**：匹配「乱世传闻 · 数字」，应为 0。出现就是又混进了循环生成的空洞事件。
- **君王分布**：确认解锁链在跑（沿用存档时后面几局应该出现初始 4 位以外的君王）。
- **中途异常**：会截图到 `$TMPDIR`，不打断整批。出现多次就去看截图。

## 改数值时要一起想到的

- **新增人才名字必须同时在 `rules.ts` 的 `TALENT_BOONS` 里补加成**，
  否则它只是个没用的收集物。军制 `ARMY_BOONS`、配偶 `SPOUSE_BOONS` 同理。
- **新增事件要标 `phase`**（蛰伏/立足/逐鹿/问鼎/建国），否则抽牌会错幕。
- 当前立国要求：军事 ≥58 / 政治 ≥58 / 经济 ≥55 中至少两项 + 天命 ≥38，并抵达终局。
  动门槛比动单个事件的影响大得多——动完必须重跑。
- 当前文字变故先示警，天命恢复 ≥56 清除警讯；归零立即失败。交涉拨款在成功或失败结算后扣除，不能被被动加成打折。旧六资源粮草军需不是当前规则。
